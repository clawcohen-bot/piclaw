# Piclaw Vision

Piclaw should be a simple, flexible, and minimal claw.

The project should stay easy to understand, easy to run, and easy to adapt.

Core principles:

- Keep the core small and focused.
- Make extensions easy to add.
- Make customization simple for personal needs.
- Prefer clear code over clever code.
- Avoid unnecessary complexity.
- Let users connect Piclaw to the tools and workflows they actually use.
- Keep core features in core: connectors, model selection, provider login/logout, cronjobs, skills, configuration, and the extension API.
- Keep product/workflow features external: wiki, calendar, CRM, task managers, notes, and personal automations.

Long-term goal:

Piclaw should become a lightweight open-source base that people can extend into their own personal or team claw without fighting the framework.
